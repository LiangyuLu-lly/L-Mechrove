L-Mechrevo 更新日志
===================

beta21  2026-09-30
-------------------
- 性能模式重做：主界面五个模式按钮直接切换，托盘列出全部模式（最多可新建 12 个自定义模式）；点「自定义」或托盘「性能模式设置…」打开编辑器，改名、删除、调全部参数，每一项都显示是否真的生效。内置模式改了功耗墙、显卡功率或风扇曲线后，会自动改用固件自定义档承载——真机实测固件只在自定义档下执行这几项。取代 beta20 的右键「二级自定义」。
- 显卡模式按显卡代际适配：GTX 10/16、RTX 20 提供 NVIDIA「首选图形处理器」（自动选择 / 独显优先）；30/40/50 按官方方式切换，50 系支持不重启切换。按钮高亮按硬件实际状态显示，读不到时显示「未确认」；切换失败自动恢复，需要重启的切换在开机后自动核对是否生效。
- 电池一行显示供电方式（圆口 / Type-C）和充电状态（充电瓦数、已充满、已到充电上限等）；鼠标悬停可看电压、循环次数，适配器功率只在能确定时显示。
- 灯光只显示本机真有的（键盘、灯条、Logo、铰链灯、同步灯带），每一行显示是否生效。
- 新增「问题反馈」：设置 → 隐私与反馈 → 问题反馈，写几句描述即可发送（可附带系统信息和脱敏日志），发送后会得到一个编号。
- 匿名统计：首次打开时说明会发送哪些匿名信息（不含用户名、计算机名、文件或设备地址），可在「设置 → 隐私与反馈」随时关闭，关闭后不再发送任何数据。
- 始终以管理员身份运行：从开始菜单或快捷方式打开时自动切换到管理员权限，一般不再每次确认。
- 软件内更新改为静默安装：点更新后自动下载、安装并重新打开，完成后提示结果；没装上会说明原因并保留旧版。
- 安装包：升级时保留 GCU 里的模式与风扇曲线；自动卸载官方控制台（此前的清理实际从未生效）；GTX 10/16、RTX 20 机器安装官方旧版服务；修复 .NET 运行时自动下载总是失败；修复一处导致「充电上限重启后失效」的权限问题；只在确实需要时才提示重启。
- 温度、风扇读数过期时显示「—」，不再显示 -1°C 或停在旧数字上；风扇停转时照实显示 0%。
- 后台占用：托盘常驻内存约 29 MB（原约 150 MB），主窗打开约 67 MB，CPU 占用约 0.1%～0.7%（单核）。
beta20  2026-09-28
-------------------
- 新增内置模式二级自定义：静音模式 / 平衡模式 / 静音狂暴 / 狂暴每个模式按钮右键（或托盘菜单「二次自定义」）都能为该模式单独设置 Windows 电源模式、处理器睿频、风扇增强、屏幕刷新率，狂暴模式还可以关闭官方的显卡自动超频（+105/+500 MHz）。切换到该模式、插拔电源或唤醒后自动应用，每一项都回读确认，没生效的会逐项列出。功耗墙、TGP、风扇曲线在非自定义档下 GCU 不接受写入，所以只在「自定义」模式里提供，不做成摆设。
- 新增自定义档命名：与官方一致，最多 12 个字符，写入后回读确认。
- 充电上限重新开放：设置后程序会在接通电源时观察实际充电行为，确认电量确实停在上限附近才算生效；如果证实本机不受控，会自动恢复满充并隐藏该项，不再显示一个拖了也没用的滑条。
- 修复多处「看起来成功、实际没生效」：深度睡眠、校色、自动刷新率、响应加速、键盘/灯条/Logo 灯效、刷新率、开机自启动、托盘菜单操作、显卡切换，在失败或 GCU 未连接时都会回到实际状态并弹出提示。
- 修复不受支持机型的只读模式下托盘菜单仍能写硬件的问题；AC 断电恢复、狂暴模式、MiniLED、响应加速按服务端上报的「不支持」如实隐藏。
- 修复日/夜主题切换后性能、显卡、电池三行的图标消失。
- 修复 GCU 连接被反复踢下时的快速重连风暴，以及一处未处理的后台异常。
- 界面：底栏改为图标加两字标签（悬浮/设置/更新/赞助/诊断/退出），文字不再压住图标；二级自定义、键盘灯效、首次引导、设置、赞助、自定义模式等窗口在 100%~200% 缩放下不再裁字或溢出，夜间模式下拉框不再是白底（UI 审计 690 张截图 0 问题）。
- 流畅度：开机自启动状态、机型识别、托盘悬停读取传感器都移出了界面线程；窗口隐藏到托盘时暂停界面刷新，重新打开时立即补齐；GCU 重连时合并重复的界面刷新；修复托盘菜单的字体句柄泄漏。
- 修复从静音/平衡/狂暴点「自定义」第一次切不过去、要再点一次的问题（GCU 会丢掉第一条切换命令，现在自动重发一次）；同时修复切换没成功时界面闪成自定义、电源计划被误改成自定义档计划的问题。
- 修复部分 Intel 机型自定义档的功耗墙显示成 210/210/420、写入无效的问题（被误判成 AMD 平台）：现在以服务端上报的平台标志为准，显示与写入都走 Intel 的 PL1/PL2/PL4。
- 二级自定义设置的 Windows 电源模式在切换模式后会被厂商服务改回：现在应用后几秒内自动复查，被改回就重新设置。

beta19  2026-09-24

beta18  2026-09-18
-------------------
- 修复「重启后不自动启动」的权限根因：自启动自检此前是「先删计划任务、再重建」，删除总成功、重建在权限不足或任务被占用时会失败，用户因此永久失去自启动项；失败又只写进默认关闭的日志，等于静默失败。现在改为就地覆盖注册（决策接口上不再有删除动作），并让注册失败通过托盘气泡对用户可见。
- 安装包改为框架依赖发布：不再随包分发 .NET 运行时文件，应用改用 .NET 桌面运行时 10（x64）。安装程序在复制任何文件之前先读注册表检测运行时（HKLM64\...\x64\sharedfx\Microsoft.WindowsDesktop.App 是否有 10.x），缺失时可从 Microsoft 官方地址自动下载并静默安装（带 SHA-256 校验）并在安装后复检；自动安装失败或用户选择手动时打开官方下载页面；/VERYSILENT 下自动安装失败则非零退出，不弹浏览器。不打包任何离线运行时。
- 应用载荷从 219,601,876 B（自包含单文件）降到 34,725,107 B（框架依赖，67 个文件），安装包随之缩小。

beta16  2026-09-15

- 新增「导出诊断包」：底栏新增「诊断」键（托盘右键菜单同入口），一键把系统信息、日志与配置打包成 zip，方便反馈问题时附带完整现场。
- 新增「GCU 连接状态」指示灯：显示 GCU 已连接 / 连接中 / 未连接，颜色之外另有文字与圆点作形状信号；服务停止后如实变红并自动重连。
- 显卡超频：非管理员运行时不再假装可写，直接显示「超频需要管理员权限」并提供「以管理员身份重启」入口，提权后控件才恢复可编辑。
- 修复「更新窗口要关两次」：更新键的 Click 被重复绑定，一次点击会先后弹出两个模态窗口；已移除重复接线。
- 修复开机自启动：自启动项不再指向单文件自解压的临时目录（从临时副本运行时不重写持久任务），避免清理后开机静默失效。
- 修复电池充电限制显示：以 EC 实际阈值为准，写入回读延迟时按实际值收尾，不再显示未知或回退。
- 修复空带与排版：设置里隐藏内容时同步收起行高，不再留下空白带；不支持机型隐藏功能后其余内容正常回流。
- 安全：更新客户端迁移到业主自建的 OSS 静态 JSON 后端，新增 7 条 fail-closed 规则（必备合法 SHA-256、仅 HTTPS、下载主机白名单、基址非法只回退到业主 OSS、版本号合法性、拒绝降级、校验失败即删除临时包）。
- 内部：清理零引用死代码、移除 NAudio 依赖；UI 审计新增空带 / 底栏遮挡等防回归检测（本轮新增发现 0）；扩充诊断包、GCU 指示灯、GPU 超频提权门控、更新安全硬化等测试。

beta15  2026-09-14
-------------------
- 修复显卡超频开关打开后状态一直显示「未确认」：根因是开关状态被硬件回读覆盖（零偏移的开启驱动不确认），现在引入用户意图状态 _gpuOcArmed，关闭开关时仍保留用户设置的数值。

- 修复电池充电限制显示 -1 且写入静默失败：根因是配置键缺失时的 -1 哨兵被原样显示、写入被静默忽略；现在手势处捕获通行证后应用，未知值显示「—」，拒绝时记录日志并如实回显。

beta9.6  2026-08-25
-------------------
- 支持热切换的机型可以免重启从混合模式切到核显；不支持的机型继续走重启切换并会提前提示。
- 显卡区新增“自动模式离电切核显”和“允许关闭独显程序”开关，只有机型支持时才显示；关闭独显程序需要额外确认。
- 切到核显前会列出占用独显的程序，可以选择先关闭、改用重启切换或取消；未真正切换成功不会显示成已生效。
- 水冷泵速和风扇档位改为等设备回报确认后才算成功，设备拒绝时界面会退回上一个档位。
- 修复键盘亮度显示与实际不一致，以及睡眠唤醒、重连后灯效重复恢复的问题。
- 关灯状态、睡眠时间和灯效速度跨重启保持；电池临时熄灯后来电或唤醒会恢复，主动关灯则保持关闭。
- 显卡超频提权被拒绝后不再反复弹窗，提权回读会确认核心与显存频率是否真的写入。

安全性
- 从解压即用的目录运行时，不再注册以系统最高权限开机执行的充电限制任务：这种目录任何程序都能改写本程序，会被利用来提权。登录后仍会正常应用充电限制；需要开机阶段就生效的话，把程序装到 Program Files 这类只有管理员能写的目录。
- 恢复官方控制台时会逐项校验要还原的内容，只还原当初记录下来的那些启动项和文件，不会被篡改过的状态文件牵着写入系统其它位置。
- 显卡超频的提权助手现在校验请求来源，空闲 5 分钟自动退出（原为 20 分钟），失败或退出程序时会一并结束，不再留下多余的高权限进程。

稳定性
- 修复某些机型上性能模式、功耗墙、温度墙、超频回读整块失效的问题：只要状态里有一个字段的格式与预期不同，整帧数据都会被丢掉，而且没有任何日志。
- 修复部分机型显示了本机并不支持的显卡切换选项，点了之后必然失败。
- 修复 Intel 机型上功耗墙设不上、且功耗显示为 0W 的问题。
- 风扇增压、独立风扇控制、自动刷新率不再出现"显示支持但开关永远是关闭"。
- 显卡热切换过程中点性能模式不再长时间没有反应。
- 液冷的泵速、风扇、灯效命令改为排队执行，不会互相打断导致设备停在混合档位或误报写入失败。
- 快速连点两个性能模式按钮不再出现界面显示的模式与实际不一致。
- 修复隔离官方控制台时，如果状态文件损坏会丢失原始启动项记录、之后"恢复"却报成功的问题。现在读不到就会中止并提示。
- 恢复官方控制台时某一项失败不再中断其余项，且不会在实际没恢复任何东西时报告成功。
- 隔离时的识别范围收紧，不再可能误禁用与官方控制台无关的开机启动项或系统计划任务；结束官方界面进程时不再连带关闭它启动的更新程序。
- 修复非管理员运行时，自动修复开机自启动会顺带删掉充电限制任务且不再重建的问题。
- 退出程序时如果还有命令在执行，不再可能卡住或报错。
- 操作失败现在都会写进日志，不再出现"点了没反应但日志里什么都没有"。
